# Finanças do Casal

App de celular (PWA) para responder, em 2 segundos: **"Quanto ainda podemos gastar nesta semana sem estourar o mês?"**

- Especificação: [`SPEC.md`](SPEC.md)
- Configuração pelo celular: [`SETUP.md`](SETUP.md)
- O que mudou em cada etapa: [`CHANGELOG.md`](CHANGELOG.md)

O site é só a interface. Os dados ficam numa planilha no Google Drive de quem usa e só aparecem depois do login Google. Sem login, o app abre em **modo demonstração**, com dados fictícios.
